# 가상의 메크 스포츠(MOBA 방식) 매니저 — 게임 설계 정리

> FM(풋볼 매니저)의 관리 시뮬레이션 구조를 토대로, 캐릭터 수집형 모바일 게임 + 로그라이트 런 구조로 재구성한 기획.
> 문서 구성: **확정 사항**(기획자 결정) / **검토 제안**(논의 중 나온 제안) / **미결 사항**

---

## 1. 게임 개요

- 장르: 캐릭터 수집형 모바일 게임 + 감독 매니지먼트 시뮬레이션 + 로그라이트 런
- 소재: 가상의 메크 스포츠, 경기 방식은 MOBA
- 레퍼런스
  - **풋볼 매니저**: 감독/스태프 능력치, 위임 구조, 선수 관리
  - **프로젝트 좀보이드**: 긍정/부정 특성과 포인트 시스템
  - **우마무스메**: 시나리오 구조, 런 단위 육성과 초기화

---

## 2. 런 구조 (확정)

- 인게임 진입 전, **보유 컬렉션에서 선수 5명을 선정**해 시작
- 런 중 스카우트·이적 없음. 선택한 5명으로 월즈 우승까지 진행
- 진행 흐름: 정규 시즌 → 플레이오프 → 월즈
- 플레이오프 또는 월즈 중 **우승 실패 시 게임오버**
- 런 종료(우승 또는 실패) 시 점수 지급. 보너스 점수가 최종 점수에 영향
- **런 길이**: 최소 약 30분(모든 이벤트 스킵) ~ 최대 약 1시간

### 런 종료 후 남는 것 / 사라지는 것 (확정)

| 구분 | 내용 |
|---|---|
| 초기화 | 런 중 키운 선수의 성장도(능력치, 메크 숙련도 등) |
| 유지 | 캐릭터 업적: POM, 최고의 선수, 감독과의 특별한 인연 이벤트(캐릭터 진엔딩) 등 |
| 유지 | 런 중 해금한 감독 특성 (**실패해도 그대로 획득**) |
| 지급 | 진척도에 따른 아웃게임 재화 (**실패 시에도 지급**) |
| 다음 런에 영향 | **감독 특성만** 영향을 줌 |

- 선수 성장은 우승 또는 특성 파밍을 위한 수단이며, 업적 콜렉팅 외에 다음 런에 영향 없음

## 3. 경기 레이어 (참고)

> 이미 게임 엔진에 구현되어 있으므로 본 문서에서는 상세히 다루지 않음.

- 타일 위에서 자동으로 진행되는 **SRPG + 덱빌딩 카드 게임** 형태
- **전략 턴에만** 전략 카드를 사용해 선수들을 조종
- 그 외 턴에는 선수 스탯에 따라 자동 전투 및 자동 조작

---

## 4. 선수 수집, 돌파, 샐러리캡 (확정)

- 다른 수집형 게임과 같이 **P2W 구조를 안고 감**
- 선수마다 **샐러리** 존재
- 시나리오마다, 팀별로 **선수 전체 샐러리캡** 존재
- 정해진 캡 안에서 팀 구성을 짜야 함 (예: 비싼 선수 2 + 싼 선수 3 / 평균 샐러리 선수 5 …)
- 선수 샐러리는 **팀 운영 예산과 연결하지 않음**. 시나리오별 팀 구성 시 샐러리캡을 맞추기 위한 장치로만 사용 (복잡도 관리 목적)

### 돌파 단계별 보너스 (확정)

| 돌파 회차 | 보너스 |
|---|---|
| 1~5회차 | 단계별로 아래 중 특정 보너스 추가 |
| | · 스탯 고정치 추가 (초반 부스팅) |
| | · 스탯 성장치 추가 (후반 위주) |
| | · 샐러리 감소 |
| | · 선수 카드 효과 변화 (고회차) |
| 6회차~ | 중복 획득 시 가챠 재화로 변환 (아래 참고) |

- 위 수치는 게임(시나리오)마다 조절 가능
- **6회차부터**: 캐릭터 가챠에서 같은 캐릭터를 뽑으면 **가챠 재화**로 변환
  - 가챠 재화는 정해진 선수 풀 중에서 원하는 선수를 **확정 구매**하는 데 사용

### 선수 레벨 (확정)

- 레벨 범위: **1~10**
- 레벨업 시 선수의 **기본 스탯(고정치)과 샐러리가 동시에 상승**
- 레벨은 **게임 시작 전에 조절** 가능
  - 달성한 최대 레벨 이하에서 자유롭게 선택 (레벨 10 달성 시 1~10 중 선택, 레벨 1이면 1만 선택 가능)
- 의도
  - '내가 좋아하는 선수'를 레벨업해 높은 스탯으로 높은 점수를 노릴 수 있음
  - 대신 샐러리 상승으로 **샐러리캡에 걸릴 위험** 증가 → 나머지 선수의 스펙을 낮춰야 함
  - 시나리오의 캡에 맞춰 선수별 레벨을 **적당히 조절**하는 것이 편성 전략이 됨
- 레벨업 재화는 주간패스 보상으로 제공

### 캐릭터 진엔딩 (확정)

- 조건: 특정 캐릭터와 **외출 5회** + **리그 우승**
- 외출은 면담, 이벤트 선택지 등으로 **신뢰도를 쌓은 이후부터** 가능
- "항상 같은 5명" 메타를 깨고, 특정 캐릭터의 엔딩을 목표로 하는 런을 만드는 장치

### 샐러리캡과 시나리오 (확정)

- **샐러리캡 높낮이에 따라 시나리오를 분리**
- 캡이 낮은 시나리오: 무/저과금 유저도 경쟁력 / 캡이 높은 시나리오: 컬렉션 깊이가 빛나는 무대

### 선수 레벨 설계 원칙 (확정)

- 레벨당 스탯/샐러리 효율은 **모든 선수가 동일**
- 레벨은 "올리면 무조건 좋음"이 아님
  - **높은 샐러리캡 시나리오에서 사용할 가치가 생기는 컷**
  - 목적은 성능 향상이 아니라 **선택지 다양화**

### 검토 제안

- **돌파 샐러리 감소 × 레벨 샐러리 상승**: 돌파로 깎은 샐러리만큼 레벨을 더 올릴 수 있으므로, 두 시스템이 같은 축(샐러리 여유)에서 상호작용함. 돌파 선수의 실질 상한이 어디까지인지 함께 시뮬레이션 필요
- **1~5회차 샐러리 감소 주의**: 스탯 상승과 샐러리 감소가 동시에 들어오면, 같은 캡 안에서 돌파 선수가 이중으로 유리해짐. 샐러리 감소 단계를 시나리오별 조정 대상에 명시해 두고, 캡이 낮은 시나리오에서 격차가 과도해지지 않는지 점검 필요

## 5. 감독 특성 시스템 (확정)

- 아웃게임 감독(플레이어 캐릭터) 성장 요소
- **부정 특성**: 감독 스탯 감소 또는 인게임 운영 페널티 → 대신 **보너스 점수 제공**
- **긍정 특성**: 스탯 상승 또는 운영상 특수 이점 → 대신 **보너스 점수 소모**
- 보너스 점수는 마이너스 불가 (최소 0)
- 보너스 점수는 런 종료 시 지급되는 점수에 영향

### 특성 획득 경로 (확정)

- 기본 제공 특성 몇 개
- 인게임에서 **특성 조건 만족 시 해금** → 다음 게임부터 장착 가능
- **시나리오 전용 특성은 두지 않음**
  - 시나리오 = 게임 시작 전 선택하는 특수 기믹 또는 배경 (우마무스메 시나리오와 동일한 개념)
  - 대신 **시나리오 보너스 특성**: 특정 시나리오에서 수치가 변동되어 직접적인 보너스를 받는 특성
  - 시나리오별 **추천 특성** 제공
  - 시나리오마다 특성과 감독 스탯에 따른 **메타를 유도**하는 방향
- **감독 특성 가챠**: 아웃게임 재화 또는 주간패스 가챠권으로 진행
- **감독 특성 제작**: 주간패스의 특성 재료를 모아 고정된 감독 특성 제작

### 특성 레어리티 (확정)

- 등급: **일반 - 고급 - 희귀 - 서사 - 전설**
- 레어리티마다 **획득 확률**과 **조합(제작) 재료**가 다름
- 등급이 높을수록 **보너스 점수 대비 가성비**가 좋음
- 의도: 게임 깊이보다 **캐주얼함**을 노림
- "공짜 부정 특성", 밸런스 인플레이션, 밸런스 실패 가능성을 **인정**하고 레어리티 체계로 수용

### 밸런스 방침 (확정)

- 특정 선수와 시너지가 강한 특성의 너프로 인한 **간접 너프는 의도된 것**

### 검토 제안

- 과금은 "얼마나 강하게 시작하나", 특성은 "얼마나 잘 운영하나"로 역할 분리 → 특성이 무과금 유저의 실력 표현 수단이 됨
- 시나리오 보너스 특성은 그 시나리오의 기믹과 연관될수록 효과적 (예: 예산 삭감 시나리오 → 절약형 특성의 수치 상승)
- 특성 수집 완료 시 메타 성장이 멈출 수 있음 → 신규 시나리오 + 시나리오 보너스 특성을 정기 업데이트 축으로 설계 (신규 선수 가챠와 함께 두 축)

## 6. 감독 스탯과 스태프 (확정)

- 감독은 스태프와 동일한 스탯 체계를 가짐
- **스탯 총합은 고정**. 분배는 감독 레벨에 따라 얻는 전문화 포인트로 조정 (아래 '감독 레벨' 참고)
- **런 중에는 감독 스탯 변경 불가**
  - 이벤트 등의 효과로 스탯 보정이 들어갈 수 있으나 **일시적** (성장과 구분)

| 스탯 | 영향 | 담당 스태프 |
|---|---|---|
| 훈련 | 훈련 수준 해금 (보유 훈련의 효과 상승, 후반에 좋음) | 훈련 코치 |
| 전술 | 훈련 종류 해금 (여러 훈련을 골고루, 한 번에, 초반에 좋음) | 전술 코치 |
| 지식 | 메크 숙련도 (새 메크 적응, 기존 메크 숙련도), 선수 파편 스킬 | 메크(지식) 코치 |
| 멘탈 | 선수 관리 (면담, 외출, 사건) | 어시스턴트 매니저, 코치 (스태프는 **사건에만** 관여) |
| 분석 | 상대 팀 전력(메크 적응도 등) 분석 | 분석가 |
| 관리 | 팀 예산 | 예산 관리자 |

- 코치는 **스탯당 1종류씩 총 3종류** (훈련/전술/지식)

### 스태프 등급과 배치 규칙 (확정)

- **일반 스태프**: 코치, 분석가, 예산 관리자 등 전용 직업. 직업 관련 스탯만 높음
- **상위 스태프 — 어시스턴트 매니저**: 감독 대체직. 여러 스탯이 출중하게 높음. 팀에 단 하나만 존재
  - 체스의 **'퀸'**, 또는 **조커 카드** 같은 존재
  - 다른 스태프로 메우기 어려운 부분을 메워주는 역할
- **각 스태프는 한 분야에 한 명만** 배치 가능
- **여러 빈자리를 동시에 메우는 것은 감독만 가능**

### 감독 레벨과 전문화 포인트 (확정)

- **감독 타입**: 게임 시작 시 선택
  - **운영형(남성)** / **실전형(여성)**
  - 세계관 설정상 선수는 여성만 될 수 있음 (서브컬처 장르)
  - 인게임에서 운영형은 남성, 실전형은 여성으로 취급되어 **이벤트 반응이 소소하게 달라지는** 정도의 차이
  - 감독 레벨이 오를수록 타입에 따른 스탯 차이는 의미가 없어짐
  - 프레스티지 초기화 시 **재선택 가능**
- **초기 스탯**: 감독 타입에 따라 정해진 값으로 시작
  - 특정 스탯에 편향되지 않고 골고루 분배
  - 주로 필요하지 않은 스탯에 분배되어 있는 경우가 많음
  - 대부분 스태프보다 낮은 수치
- **레벨 범위**: 1~25. 매 게임 진척도에 따라 **감독 경험치** 획득
- **레벨업 시**: 스탯 중 1점을 **전문화 포인트**로 변환 가능
  - 변환된 전문화 포인트는 **런과 런 사이에만** 다른 스탯에 재분배 가능 (런 중 변경 불가)
  - 총 전문화 포인트 24점 (레벨 25 기준) → 최대 24점의 스탯을 재분배
- **프레스티지**
  - 감독 레벨 25에서 프레스티지 레벨을 1 올리고 감독을 **레벨 1로 회귀**
  - **전문화 포인트만 초기화**. 그 외 모든 것은 유지 (보유한 감독 특성 등 그대로 사용 가능)
  - **시즌당 1회**만 가능
  - 해당 시즌에 맞는 **코스메틱 보상** 획득
  - 예상 플레이 패턴
    - 꾸준히 플레이한 유저: 이전 시즌에 만렙 → 새 시즌 시작 시 바로 프레스티지하고 보상 획득 후 진행
    - 이전 시즌에 쉬었던 유저: 이번 시즌 보상이 마음에 들면 열심히 플레이해 만렙 → 보상 획득

### 감독 프리셋 (확정)

- 런 전 감독 준비 편의를 위한 기능
- 프리셋 구성: **감독 스탯(전문화 포인트 분배) + 감독 특성**
- 기본 **5개** (일반 프리셋)
- **일반 프리셋 / 프레스티지 프리셋** 구분
  - 프레스티지 시 기존 프리셋은 **프레스티지 프리셋으로 변환**
    - 이전 레벨의 전문화 포인트를 기준으로 설정된 세팅이므로 **당장은 사용 불가**
    - 단, 프레스티지 프리셋은 **언제든 초기화 후 재설정** 가능 → 현재 포인트 기준으로 다시 세팅하면 사용 가능
  - 일반 프리셋 1개가 새로 추가되고 **자동 장착**
- 진행 예시

| 프레스티지 레벨 | 프레스티지 프리셋 | 일반 프리셋 | 총합 |
|---|---|---|---|
| 0 | 0 | 5 | 5 |
| 1 | 5 (기존 5개 변환) | 1 (신규, 자동 장착) | 6 |
| 2 | 6 (일반 1개 변환) | 1 (신규, 자동 장착) | 7 |
| 3 | 7 | 1 | 8 |
| 4 | 8 | 1 | 9 |
| 5 | 9 | 1 | **10 (최대)** |

### 스태프 변동 방침 (확정)

- 팀별 **초기 스태프 수준은 고정** (범위 랜덤은 리세마라 위험이 있어 사용하지 않음)
- **런 중 스태프 이탈 없음** (불쾌감이 큼)
- **일시적 스탯 보정 이벤트**로 런 중 변화를 줌

### 커버 규칙 (확정)

- 감독 스탯이 스태프의 빈자리를 커버하거나, 감독의 빈자리를 스태프가 커버하는 방식
- **최댓값 판정**: 같은 스탯에 대해 감독, 어시스턴트 매니저, 일반 스태프 중 가장 높은 값 적용
- 활용 예
  - 관리하기 귀찮은 항목(예산 관리 등)을 스태프로 자동화
  - 일부러 특정 스탯에 몰빵한 뒤, 부족한 스탯을 스태프로 메움
  - 스태프 예산을 줄이기 위해 감독이 직접 뜀

### 검토 제안

- 멘탈은 면담·외출이 감독 전용이라 어떤 팀을 골라도 감독이 직접 손대는 영역이 보장됨 → 감독 존재감 유지 장치
- 감독 스탯 총합은 **1~2개 영역을 스태프 수준으로 커버할 수 있는 정도**로 튜닝. 너무 많으면 스태프 불필요, 너무 적으면 몰빵 전략만 남음 → 전문화 포인트 24점을 모두 모았을 때 이 수준에 도달하도록 설계
- **감독 레벨 = 학습 곡선**: 저레벨 감독은 스탯이 흩어져 있어 스태프 의존도가 높으므로 고예산 팀과 궁합이 좋고, 레벨이 오를수록 특정 영역을 직접 맡을 수 있어 저예산 팀 도전이 가능해짐. 팀 난이도 사다리와 감독 레벨 진행을 맞물리게 설계 가능
- **"필요 없는 스탯에 초기 분배"**는 재분배의 동기를 만드는 좋은 장치
- 감독 타입이 레벨업과 함께 의미를 잃는 구조이므로, 타입 차이는 초반 체감과 이벤트 반응(캐릭터성)에 집중되는 것이 자연스러움
- **프리셋 × 특성 해금**: 특성이 런마다 해금되므로, 프리셋에 저장된 특성의 보너스 점수 합계가 바뀌지 않도록 특성 비용이 고정인지 확인. 프리셋 적용 시 보너스 점수가 0 미만이 되는 조합은 저장 단계에서 차단
- **프레스티지 타이밍**: 꾸준한 유저는 시즌 초에 프레스티지하므로, 시즌 초반에는 전문화 포인트가 적은 상태로 랭킹 경쟁을 시작함. 시즌 초 레벨 회복 속도(감독 경험치 획득량)가 시즌 초반 플레이 체감을 결정
- 초기 스태프 수준이 고정이므로 팀마다 정답 분배로 수렴할 가능성은 남음 → 시나리오별 메타 유도와 일시적 스탯 보정 이벤트로 런마다 변화를 주는 것이 핵심

## 7. 팀 선택과 예산 (확정)

- 게임 시작 시 **8개 팀** 중 선택
- 팀마다 예산, 스태프 수준, 시작 시설 수준이 다름
- **예산이 높을수록 난이도가 쉬움**
- 예산이 낮을수록 감독이 스태프 대신 직접 신경 써야 할 항목이 늘어남 (예산 투자가 많이 필요한 항목부터 담당)
- **예산 마이크로 컨트롤과 최적화가 게임 난이도를 결정**

## 8. 매니지먼트 요소 해금과 학습 곡선 (확정 방향)

- 단순한 "귀찮음 자동화"를 넘어, 난이도가 올라갈수록(예산 삭감) 예산 최적화를 위해 **여러 매니지먼트 요소가 해금되는 느낌**을 주는 것이 목표 (학습 곡선)

### 검토 제안

**자동화와 수동 조작 분리**
- 스태프가 담당 → 해당 영역 자동 처리 (돈으로 편의를 삼)
- 감독이 직접 커버 → 스탯은 적용되지만 수동 조작 필요. 대신 잘하면 자동보다 나은 결과 가능

**비용 순서 = 학습 순서**
- 위임 비용이 비싼 순서가 곧 배우기 쉬운 순서가 되도록 설계
- 8개 팀 사다리 예시
  - 최상위 예산: 전략 카드 운영, 선수 면담만 직접
  - 중상위: + 훈련 일정 편성
  - 중위: + 메크 숙련도 관리
  - 중하위: + 상대 분석 해석
  - 최하위: + 예산 배분, 시설 유지, 스태프 연봉
- 팀 선택 화면에서 "이 팀은 무엇을 직접 해야 하는지" 표시

**시스템별 깊이 단계**
- 예: 예산 관리 = 영역별 배분 슬라이더 → (더 낮은 예산 구간) 스폰서 계약 선택, 시설 유지보수 연기, 스태프 연봉 재협상
- "예산이 부족해서 새 수단을 써야 한다"는 압박이 해금의 명분 → 메뉴 증가가 아니라 도구 획득으로 느껴지게

**서사적 전달**
- 특정 영역을 처음 직접 맡게 되는 런의 시작 시점에 이벤트 연출 (예: 이 팀에는 분석가가 없음 → 어시스턴트가 가이드)
- 런 중 스태프 이탈은 사용하지 않으므로, 런 내부의 변화는 일시적 보정 이벤트로 연출

**메타 성장 연결**
- 수동 운영 경험을 특성 해금 조건과 연결 (예: 예산 관리를 직접 맡아 흑자로 시즌 종료 → 관련 긍정 특성 해금)

**피로도 관리**
- 최하위 팀의 관리 부담 상한 설정
- 한 시즌 내 반복 결정 횟수 기준으로 피로도 점검 (런 길이 30분~1시간 기준)
- 시즌 시작 시 한 번 정하면 유지되는 결정 / 매 경기 정해야 하는 결정을 구분

## 9. 아웃게임 재화와 보상 구조 (확정)

### 아웃게임 재화
- 런 진척도에 따라 획득 (실패 시에도 지급)
- 사용처: **감독 특성 가챠**, **선수 가챠(낮은 등급)**

### 주간패스 (무료)
- **유료 트랙 없음**. 온전히 무료로 받을 수 있는 보상들의 패스
- 레벨 **25**까지 존재
- **런에서 얻은 점수**로 패스 경험치를 채움
- 레벨 **26부터**는 점수가 아웃게임 재화로 변환
- 보상 구성

| 보상 | 내용 |
|---|---|
| 가챠권 | 감독 특성 가챠권, 낮은 등급 선수 가챠권 |
| 선수 레벨업 재화 | 선수 레벨업(1~10)에 사용 |
| 코스메틱 재화 | 모아서 선수 스킨, 메크 스킨, 시설 스킨 구매 |
| 감독 특성 재료 | 모아서 고정된 감독 특성 제작 |
| 확정 코스메틱 | 특정 시즌마다 고정. 이미 보유 시 코스메틱 재화로 변환 |
| **최종 보상: 유료 재화** | 프리미엄 선수 가챠, 또는 유료 패스 구매에 사용 |

### 유료 패스 (추후 추가 예정)
- **유료 재화**로 구매 (주간패스 최종 보상으로도 유료 재화 획득 가능)
- 주간패스와 마찬가지로 **런 점수로 진척도를 채움**
- **여러 개 동시 활성화** 가능
- 한 번 구매하면 **계정에 영구 귀속**, 기간 제한 없음
- 단, **시즌 유료 패스**는 해당 시즌 동안 런 점수 보너스를 받아 진척도를 더 쉽게 채움
- 한 시즌에 **유료 패스 3~4개** 진행 예정
- 진척도별 보상
  - 프리미엄 선수 가챠
  - 유료 재화 (페이백)
  - 최종 보상: 유료 패스마다 정해진 **고등급 선수 확정 획득**
- 만렙(25) 도달 시 구매에 사용한 유료 재화의 **약 절반 페이백**

### 검토 제안
- 주간패스가 완전 무료이고 감독 특성 관련 보상이 무료 트랙에만 있으므로, "특성은 과금과 무관 → 밸런스 조정 자유" 전제가 유지됨
- 주간패스 최종 보상(유료 재화) + 유료 패스 페이백(약 50%)이 맞물리면, 꾸준히 플레이하는 무과금 유저도 유료 패스를 이어서 구매하는 루프가 가능해질 수 있음. 의도에 따라 좋은 리텐션 장치가 될 수도, 매출을 깎을 수도 있으므로 **시즌 단위 재화 수지 시뮬레이션** 필요 (주간 유료 재화 획득량 × 시즌 주 수 + 페이백 vs 패스 가격 × 3~4개)
- 유료 패스 최종 보상의 고등급 선수는 샐러리캡 구조 안에서 평가되므로, 캡이 낮은 시나리오에서는 고등급 선수의 가치가 상대적으로 낮아짐. 패스 선수의 샐러리 설정이 패스 구매 매력도에 직결됨

### 랭킹
- 런 점수로 랭킹 산정
- **P2W 수용**. 랭킹 보상은 **코스메틱만** 있으므로 과금 격차가 실질적 불이익으로 크게 이어지지 않음

## 10. 미결 사항

- 현재 없음

### 본 문서 범위 외 (별도 결정)

- 돌파 1~5회차의 단계별 보너스 배치 → 선수 설정마다 개별 결정
- 감독 스탯 총합, 감독 타입별 초기 분배 등 구체적 수치
- 시즌 단위 유료 재화 수지 (무료 획득량, 페이백, 패스 가격) 등 구체적 수치
- 선수 레벨별 스탯·샐러리 상승 수치
- 가챠 재화 확정 구매 선수 풀 등 아웃게임의 구체적 로직
