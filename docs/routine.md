## 1. 타일 색상 체계 — 색이 곧 능력치

`TrainingGeneralSettingObject.colors`가 0~6번 색의 RGB를 직접 들고 있고,
모든 훈련 칸이 이 인덱스 중 하나를 가진다. 색별로 경험치 총합을 집계하면 **한 능력치에 완전히 몰려 있어**
색 ↔ 능력치 대응은 추정이 아니라 확정이다.

| # | 기호 | 색 | HEX | 능력치 | 검증 (해당 색 전체 EXP 합) |
|---:|:--:|---|---|---|---|
| 0 | `R` | 레드 | `#F49090` | 공격 | 공격 1,261 / 나머지 합 862 → **공격** |
| 1 | `B` | 블루 | `#84AFEF` | 방어 | 방어 1,746 / 나머지 합 656 → **방어** |
| 2 | `Y` | 옐로 | `#EED469` | 메카닉 | 메카닉 1,498 · 반응 775 / 공격 25 → **메카닉(+반응)** |
| 3 | `P` | 퍼플 | `#B48BFC` | 반응 | 반응 988 / 나머지 합 30 → **반응** |
| 4 | `G` | 그린 | `#88DDA6` | 파밍 | 파밍 3,428 / 나머지 합 55 → **파밍** |
| 5 | `K` | 블랙 | `#666666` | 경험치 없음 | 전 능력치 0 → **경험치를 주지 않는 보조 칸** |
| 6 | `W` | 그레이 | `#CCCCCC` | 올라운드 | 5능력치 고루 분포 → **올라운드 / 무속성** |

### 색의 게임적 의미

- **레드/블루/옐로/퍼플/그린 (0~4)** — 특정 능력치를 집중적으로 올리는 "전문" 칸.
  인접 효과의 조건절이 이 색을 직접 참조한다. (예: *탈출 훈련* = "같은 열의 **레드** 코스 하나당 방어 +40")
- **블랙 (5)** — 경험치가 **정확히 0**인 칸. 20종 전부 5능력치 모두 0이다.
  이 칸을 차지한 선수는 그 시간에 아무것도 얻지 못하는 대신, 타일이 주변에 버프를 뿌린다.
  게임 내 표현: *"이 코스의 검은 블록은 경험치를 제공하지 않습니다"*
- **그레이 (6)** — 색 조건에 걸리지 않는 무속성 칸. 5능력치를 고루 주거나 2~4개를 섞어 준다.
  *관전*처럼 "같은 열의 **색상 종류 수**"를 세는 효과에서 별개 색으로 카운트된다.

## 2. 훈련판 구조 — 행과 열의 의미

`uiData`의 방향 플래그(상/하/좌/우 × 전체/1칸)와 각 타일의 설명문을 대조하면 축이 확정된다.

```
          1교시  2교시  3교시  4교시  5교시     ← 열(column) = 같은 시간대
   탑    [  R  ][  R  ][  W  ][     ][  G  ]
   정글  [  P  ][  P  ][  W  ][  W  ][     ]   ← 행(row) = 한 선수의 하루
   미드  [  Y  ][  Y  ][  Y  ][     ][  K  ]
   원딜  [  G  ][  G  ][     ][  B  ][  B  ]
   서폿  [  K  ][  W  ][  W  ][  W  ][     ]
```

| 축 | 데이터 플래그 | 의미 | 대표 타일 |
|---|---|---|---|
| **행(가로)** | `leftAll` / `rightAll` / `leftOne` / `rightOne` | 한 선수의 시간표 | 명상, 강의, 준비, 전문화 5종, 책 읽기, 크립 스코어 3~5 |
| **열(세로)** | `upAll` / `downAll` / `upOne` / `downOne` | 같은 시간에 훈련 중인 다른 선수 | 트레이닝 파트너, 격려, 팀 전투 딜링, 탈출 훈련, 관전, 파밍 전략 |

### 배치 규칙

- 코스를 배정하지 않은 칸은 자동으로 **기초 훈련 / 기초 훈련 2**가 채운다 (`isCanDefaultFill`).
- **기초 훈련 1~5만 `isInfinite`** — 몇 번이든 반복해서 놓을 수 있다.
  나머지 82종은 보유 수량만큼만 배치 가능하다.
- `추가 휴일(CT00071)`만 `isSpeificColumn` — **1번 열(가장 왼쪽)에만** 놓을 수 있다.
- 타일은 1~6칸을 차지하는 폴리오미노다. 세로 타일은 한 선수가 아니라 **여러 선수를 동시에 묶는다**.

| 점유 칸 수 | 타일 수 |
|---:|---:|
| 1칸 | 47 |
| 2칸 | 20 |
| 3칸 | 15 |
| 4칸 | 2 |
| 5칸 | 1 |
| 6칸 | 2 |

## 5. 설계 패턴 분석

### 5-1. 타일은 4가지 역할로 나뉜다

| 역할 | 특징 | 대표 |
|---|---|---|
| **딜러형** | 색이 붙고 특정 능력치를 대량 공급. 인접 효과 없음 | 전문화 5종, 리듬 게임, 크립 스코어 2 |
| **증폭형** | 자기 칸은 블랙(경험치 0), 주변 효과를 % 로 곱함 | 트레이닝 파트너, 준비, 명상, 슈퍼비전 |
| **조건형** | 판 위의 다른 색/개수를 세서 보너스나 페널티를 계산 | 탈출 훈련, 관전, 학습 요약, 파밍 전략 |
| **보정형** | 최저/최고 능력치를 찾아 보정. 색 무관 | 약점 보완, 힘 향상 |

### 5-2. "강력함에는 반드시 비용이 붙는다"

고배율 타일은 예외 없이 페널티를 함께 들고 있다.

- **한계 돌파** — 반응·메카닉 각 +160~300 (3칸) / 대신 **왼쪽 칸 효과를 ×50%~×25%로 깎음**
- **파밍 전략** — 파밍 +420~620 (3칸) / 대신 **같은 열 그린 코스마다 -25~-30**
- **크립 스코어 3~5** — 파밍 +300~580 / 대신 **같은 행 그린 코스마다 -15~-50**
- **준비 3 (SS)** — 오른쪽 +170% / 대신 **3칸을 통째로 버리고, 재료로도 못 씀**

### 5-3. 대성공(Critical Success) = +50%

`TrainingResultTypes` 2번이 "치명적 성공 / +50%"다.
15종은 `resultCannotBeVerygood`로 **대성공 판정 자체가 발생하지 않는다** — 전부 블랙 칸 증폭형이다.
반대로 대성공 확률을 조작하는 타일이 따로 존재한다.

- **격려 1/2/3** — 같은 열의 1칸 코스 대성공 확률 +8% / +10% / +14%
- **전술 토론 1/2/3** — 자신이 대성공하면 효과 +25% / +35% / +50% (대성공 시너지)
- **추가 휴일** — 같은 행 전체 +15%, 자신 대성공 시 같은 행 전체 **+100%**

### 5-4. 색 조건이 메타를 만든다

색은 단순 분류가 아니라 **다른 타일의 조건절 입력값**이다.

| 참조하는 타일 | 조건 |
|---|---|
| 탈출 훈련 1~3 | 같은 열의 **레드** 개수 → 방어 EXP |
| 로밍 & 서포터 | 같은 열의 다른 **레드** 코스 +15% |
| 독특한 농법 | 같은 열에 **그린이 없으면** +50% |
| 파밍 전략 1~2 | 같은 열의 **그린** 개수 → 파밍 페널티 |
| 크립 스코어 3~5 | 같은 행의 **그린** 개수 → 파밍 페널티 |
| 학습 요약 1~4 | 왼쪽의 **블랙** 개수 → 전 능력치 EXP |
| 관전 1~2 | 같은 열의 **색 종류 수** → 전 능력치 EXP |
| 훈련 요약 1~2 | 왼쪽 코스의 **색에 대응하는 능력치**에 +25/+50 |

즉 편성은 "좋은 타일을 모으기"가 아니라 **"색 배치를 설계하기"** 게임이다.

### 5-5. 등급별 파워 스케일링

같은 계열의 등급별 수치를 보면 배율이 일정하지 않다.

| 계열 | Lv1 | Lv2 | Lv3 | Lv4 | Lv5 |
|---|---|---|---|---|---|
| 기초 훈련 (칸당 전 능력치) | 8 (D) | 12 (C) | 28 (C) | 34 (B) | 72 (A) |
| 크립 스코어 (파밍/칸) | 35 (C) | 70 (C) | 300 (A) | 400 (S) | 580 (SS) |
| 전문화 (해당 능력치) | 105 (A) | 108 (S) | — | — | — |
| 트레이닝 파트너 (열 배율) | +20% (C) | +30% (B) | +35% (A) | +40% (S) | +50% (SS) |
| 준비 (오른쪽 배율) | +80% (A) | +120% (S) | +170% (SS) | — | — |

- **전문화는 등급이 올라도 수치가 거의 그대로(105→108)이고, 대신 시너지 배율이 15%→20%로 오른다.**
  단독 성능이 아니라 조합 밀도로 스케일하는 설계.
- **크립 스코어는 Lv2→Lv3에서 4배 이상 점프**한다. A등급이 실질적인 파워 스파이크 지점.

## 부록: 재현 방법

```python
import UnityPy, json

BUNDLE = r"...\StreamingAssets\aa\StandaloneWindows64\setting_assets_all_*.bundle"
env = UnityPy.load(BUNDLE)

# MonoScript pathID -> 클래스 이름
scripts = {o.path_id: o.read_typetree()["m_ClassName"]
           for o in env.objects if o.type.name == "MonoScript"}

for o in env.objects:
    if o.type.name != "MonoBehaviour":
        continue
    d = o.read_typetree()
    cls = scripts.get(d["m_Script"]["m_PathID"])
    if cls == "TrainingGroupSettingObject":
        print(d["m_Name"], d["grade"], d["items"], d["uiData"])
```

한국어 텍스트는 `LanguagePackSettingObject` 중 `m_Name == "Korean"`의
`textBlocks` 에서 `key == "DailyTraining"` 블록을 찾아 `itemTextDict.kvPairs`를 펼치면 된다.
